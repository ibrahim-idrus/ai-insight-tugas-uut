# General Preferences
- Prefers simplified, minimal status systems over granular ones (e.g., two statuses instead of four). Confidence: 0.85
- Prefers profile/account access as a text button in the top-right corner rather than a sidebar navigation item. Confidence: 0.8
- Prefers direct navigation — clicking a button should go straight to the target page, no intermediate steps. Confidence: 0.8
- Prefers completed/graded items to be read-only — no upload or action prompts when viewing details of finished items. Confidence: 0.85
- Prefers key information (like grades) displayed directly on cards so it's visible at a glance without opening details. Confidence: 0.8
- Expects terminology and status label changes to be applied consistently across ALL UI surfaces (dashboard, list pages, detail pages, backend responses) — not just the primary view. Confidence: 0.85
